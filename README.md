# Azim Pizza 🍕

Сайт пиццы ручной работы, которую печёт Азим. Статический: без сборки, без сервера.

- **Анатомия**: 3D-пицца разобрана на слои с подписями. При прокрутке собирается и запекается: сыр тает, на бортике появляются подпалины, идёт пар.
- **Свежесть по часам**: путь от замеса теста (−24 ч) до печи (+3 мин), на реальных фото.
- **Меню**: 3D-превью каждой пиццы, цена и время готовки.
- **3D-конструктор**: выбор размера и ингредиентов (одинарная или двойная порция). Ингредиенты падают на пиццу. Пересчитываются цена, вес, время в печи и время готовности. Есть кнопка «В печь» и режим «Анатомия».
- **Корзина**: заказ уходит в WhatsApp готовым текстом.

## Где что менять
- Цены, размеры, ингредиенты, время приготовления, пиццы меню: `js/data.js`
- Номер WhatsApp: `WHATSAPP_PHONE` в `js/data.js`
- 3D-модели ингредиентов: `js/pizza3d.js`

## Запуск
ES-модулям нужен веб-сервер, просто открыть файл не получится:
```
python3 -m http.server 8000
# открыть http://localhost:8000
```
Можно выложить на GitHub Pages: Settings → Pages → Deploy from branch.

Three.js r160 лежит в `vendor/three` (лицензия MIT).
